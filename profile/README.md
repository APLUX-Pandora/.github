# Pandora · On-device AI Box

**From models to ready-to-integrate on-device AI solutions.**

Pandora, by **APLUX**, brings together models adapted for Qualcomm platforms, inference SDKs, and practical demos. We help developers turn AI capabilities into applications that run locally on edge devices.

## What we build

- **Voice:** real-time transcription, multilingual speech synthesis, and voice cloning.
- **Vision:** image generation and visual AI applications.
- **Integration:** runnable demos and SDKs that connect model capabilities to real product scenarios.

## Explore Pandora

- [GitHub](https://github.com/APLUX-Pandora) — demo projects and integration resources.
- [Hugging Face](https://huggingface.co/APLUX-Pandora) — model resources for on-device deployment.
- [ModelFarm](https://aiot.aidlux.com/en/models) — explore models adapted for edge hardware.
